# MathSimAI+ · Pecutan Terakhir SPM 2026

Laman ulang kaji Matematik Tambahan 3472 untuk calon SPM 2026 yang menyasarkan gred A.

Disediakan oleh **Ir. Ts. Dr. Muhammad Hafiz HASSAN**, Pusat Pengajian Kejuruteraan Mekanik, Universiti Sains Malaysia.

## Kandungan
- Papan pemuka: kira detik ke 17 Disember 2026, ramalan gred, pelan 36 hari, peta penguasaan 18 bab
- Nota infografik 18 bab dengan video penerangan beranimasi
- Aplikasi kejuruteraan: 8 kajian kes dengan video, simulator dan soalan cabaran
- Bank soalan Kertas 1 (3472/1) dan Kertas 2 (3472/2): Set Pecutan 1–3 dan set rawak tanpa had
- Simulator konsep dan analisis prestasi

Semua soalan ialah soalan asal gaya SPM, bukan soalan bocor atau ramalan rasmi. Rekod pelajar disimpan dalam pelayar masing-masing sahaja.
